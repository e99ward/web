A furnace you can experiment with

This is an educational, lumped thermal model. Temperature rises with heater power and falls through heat loss to ambient. The heater has a first-order thermal lag and transport delay.

dT/dt = H × heater / 100 − loss × (T − ambient)

Controller: Time mode uses Gc(s) = Kp[1 + 1/(Tn·s) + Tv·s/(1 + Td·s)]. Internally Ki = Kp/Tn and Kd = Kp·Tv; Td is the derivative filter time. All times are minutes. With D on error, U(s) = Gc(s)E(s) before saturation and anti-windup. With D on temperature, only the derivative input changes to −T. The filter defaults to 0.25 min and is adjustable; Td = 0 means an unfiltered derivative. Disable Integral enabled to turn I off. Changing Kp in time mode also changes effective Ki and Kd. Gain units are %/°C, %/(°C·min), and %·min/°C. Conditional integration limits windup.

Each stage ramps the setpoint to its target and then holds it for the specified time. Holds begin on the programmed schedule, even if the actual temperature has not reached the target. During the final cool-down the heater is turned off.

The simulation uses a 0.05-minute time step. Maximum overshoot excludes final cool-down; hold accuracy includes the entire hold, including its initial transient. CSV exports the complete current run.

Real furnaces also have temperature-dependent losses, changing material properties and sensor dynamics. Calibrate this model against measured data before using it to inform real equipment settings.
